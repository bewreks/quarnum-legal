# Quarnum legal pages

Static privacy pages for the Quarnum game.

## URLs

- https://bewreks.github.io/quarnum-legal/
- https://bewreks.github.io/quarnum-legal/privacy/
- https://bewreks.github.io/quarnum-legal/privacy/en/

## Publishing

The site is plain static HTML and is published with GitHub Pages from the `main` branch, repository root.

## Before store submission

- Operator name and OGRNIP are filled in. Add INN and legal address if required by the store.
- Confirm the contact email.
- If advertising, analytics or other network SDKs are added, update both language versions before enabling them.
